# Acessibilidade

Vale ao escrever qualquer HTML, componente ou página.

- Cada página tem um único `<h1>` e os títulos seguem a ordem (h1 → h2 → h3).
- Use HTML semântico: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`.
- Links externos usam `target="_blank" rel="noopener noreferrer"`.
- Botões que só têm ícone recebem `aria-label`.
- Toda imagem tem `alt`: descritivo quando informa algo, `alt=""` quando é decorativa.
